# HushWake（悄醒）

> 声音，去往正确的地方。

HushWake 是一款面向 Android 的智能输出闹钟与助眠声工具：没有耳机时使用系统媒体外放；连接耳机时验证实际耳机路由，无法确认安全则保持静音。

## 当前阶段

`0.3.0-beta` 是面向 Android 12 / API 31 及以上的完整功能测试版。它已覆盖智能输出闹钟和助眠声，但实体耳机的零串音验证仍是发布门禁，不应描述为公开稳定版。

当前版本包含：

- 一次性/周重复闹钟的创建、编辑、启停、删除、精确调度和系统事件重排。
- 到点前台服务、锁屏全屏入口或高优先级通知、停止、一次稍后提醒、最长响铃和振动兜底。
- 从闹钟主页关闭正在响铃的对应闹钟时，立即同步停止该次响铃；一次性闹钟另有明确的“立即停止”入口。
- 无耳机时使用系统媒体外放；检测到唯一耳机时，API 31–35 使用兼容验证、API 36+ 使用全路由强验证。
- 双层静音起播、实际耳机路由通过后渐强；耳机断连、焦点丢失或验证失败时停止，不转到扬声器。
- 三种有明确再分发许可的真实环境录音：绵密夜雨、林间溪流、轻柔壁炉；支持暂停、通知控制、定时和结束渐隐。
- 仅保留“闹钟”和“助眠声”两个主页面。权限、输出状态和耳机验证入口按需出现在页面内，不再提供可靠性、记录或设置页。
- 音量完全跟随系统媒体音量，应用不提供增益设置，也不会自动修改系统音量。
- 无账号、无云同步、无行为记录或诊断上传；耳机身份仅保存带本机随机盐的不可逆哈希。

## 核心原则

- 无耳机时允许正常媒体外放，并在页面明确提醒当前会使用扬声器。
- 耳机播放中断连或路由不确定时先静音并停止，不突然切回手机扬声器。
- 当前免费供个人使用和分享，不包含付费、广告、账号或云同步。

## 构建与验证

需要 JDK 17 与 Android SDK 36：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

生成的测试包位于 `app/build/outputs/apk/debug/app-debug.apk`。ADB 连接设备或模拟器后可运行：

```powershell
.\scripts\verify-app-launch.ps1
.\scripts\smoke-emulator.ps1
```

前者检查冷启动，后者自动遍历首次引导、两个主页面和闹钟编辑页。模拟器回归不能证明真实耳机不会串到扬声器，耳机安全结论仍须按实体机测试指南验证。
