# HushWake（悄醒）

> 声音，去往正确的地方。

HushWake 是一款面向 Android 的智能输出闹钟与白噪音工具：无耳机时正常使用系统媒体外放，连接耳机时验证实际耳机路由并避免串到扬声器。

## 当前阶段

`0.2.1-beta` 是当前完整功能测试版，面向 Android 12 / API 31 及以上。它已覆盖智能输出闹钟、白噪音和本地设置/记录，并修复 Android 14 上正常 A2DP 路由回调被误判为断连的问题；实体耳机的零串音验证仍是发布门禁，不应把 beta 描述为公开稳定版。

当前版本包含：

- 一次性/周重复闹钟的创建、编辑、启停、删除、精确调度、重启与时间变化后重排。
- 到点前台服务、锁屏全屏入口或高优先级通知降级、停止、一次稍后提醒、最长响铃和振动兜底。
- 无耳机时使用系统媒体外放；检测到唯一耳机时，API 31–35 使用兼容验证、API 36+ 使用全路由强验证。
- 双层静音起播、实际路由通过后渐强；路由信号先归零并重验，同一安全耳机可恢复渐强，真实断连、焦点丢失或验证失败则停止。
- 四种离线环境音、暂停、通知控制、定时和结束渐隐；白噪音与闹钟共用智能输出策略。
- 首次引导、分项可靠性中心、最近 30 次或 30 天本地记录、默认值与本地数据清除。
- 无账号、无云同步、无诊断上传；耳机身份仅保存带本机随机盐的不可逆哈希。

## 核心原则

- 无耳机时允许正常媒体外放；检测到耳机时必须确认实际耳机路由。
- 耳机播放中断连或路由不确定时先静音并停止，不突然切回手机扬声器。
- 当前免费供个人使用和分享，不包含付费、广告、账号或云同步。

## 构建与验证

需要 JDK 17 与 Android SDK 36：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

生成的测试包位于 `app/build/outputs/apk/debug/app-debug.apk`。ADB 连接设备后可运行：

```powershell
.\scripts\verify-app-launch.ps1
.\scripts\smoke-emulator.ps1
```

前者检查冷启动，后者自动遍历首次引导、五个主页面和新建闹钟页。既有 API 31、34、36 模拟器基线覆盖该流程；本版本新增的智能外放与耳机切换需在本轮 APK 和实体机上重新验证。构建、单元测试和模拟器回归不能证明真实耳机不会串到扬声器。
