# HushWake（悄醒）

> 声音，去往正确的地方。

HushWake 是一款面向 Android 的智能输出闹钟与助眠声工具：没有耳机时使用系统媒体外放；连接耳机时验证实际耳机路由，无法确认安全则保持静音。

## 当前阶段

`0.3.3-beta` 是面向 Android 12 / API 31 及以上的完整功能测试版。它已覆盖智能输出闹钟和助眠声，但实体耳机的零串音验证仍是发布门禁，不应描述为公开稳定版。

当前版本包含：

- 一次性/周重复闹钟的创建、编辑、启停、删除、精确调度和系统事件重排；退出页面或应用退到后台后仍由 Android 唤醒触发。
- Android 13+ 使用闹钟应用专用的安装即授权精确调度能力，避免 Android 14 全新安装后保存成功但没有系统闹钟；Android 12 保留兼容授权与状态提示。
- 到点前台服务、锁屏全屏入口或高优先级通知、停止、一次稍后提醒、最长响铃和振动兜底。
- 从闹钟主页关闭正在响铃的对应闹钟时，立即同步停止该次响铃；一次性闹钟另有明确的“立即停止”入口。
- 无耳机时使用系统媒体外放；检测到唯一耳机时，API 31–35 使用兼容验证、API 36+ 使用全路由强验证。
- 双层静音起播、实际路由通过后立即以可听增益开始并渐强；耳机断连、焦点丢失或验证失败时停止，不转到扬声器。
- 六种有明确再分发许可的真实环境录音，覆盖夜雨、溪流、壁炉、晨林、虫鸣和微风；播放中点选另一声音会立即切换，并保留当前定时和暂停状态。
- 闹钟编辑页提供六种 AOSP 专业闹铃素材，支持点选即试听和再次点选重播；保存后自动启用，启停开关只在列表页。正式响铃持续循环到用户停止或达到 2 分钟上限。
- 仅保留“闹钟”和“助眠声”两个主页面。权限、输出状态和耳机验证入口按需出现在页面内，不再提供可靠性、记录或设置页。
- 新版界面围绕“几点叫醒你？”和“想听什么入睡？”组织操作，使用分组卡片、声音直选和统一的高对比度深色视觉；闹钟时间采用小时/分钟双滚轮，并提供 15 分钟后、30 分钟后和 1 小时后快捷设置。
- 音量完全跟随系统媒体音量，应用不提供增益设置，也不会自动修改系统音量。
- 无账号、无云同步、无行为记录或诊断上传；耳机身份仅保存带本机随机盐的不可逆哈希。

## 核心原则

- 无耳机时允许正常媒体外放，并在页面明确提醒当前会使用扬声器。
- 耳机播放中断连或路由不确定时先静音并停止，不突然切回手机扬声器。
- 当前免费供个人使用和分享，不包含付费、广告、账号或云同步。

## 构建与验证

需要 JDK 17 与 Android SDK 36：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

生成的测试包位于 `app/build/outputs/apk/debug/app-debug.apk`。ADB 连接设备或模拟器后可运行：

```powershell
.\scripts\verify-app-launch.ps1
.\scripts\smoke-emulator.ps1
.\scripts\verify-background-alarm.ps1
```

三个脚本依次覆盖冷启动、主流程交互，以及全新安装后退到后台并被系统重新拉起的闹钟链路。模拟器回归不能证明真实耳机不会串到扬声器，耳机安全结论仍须按实体机测试指南验证。
